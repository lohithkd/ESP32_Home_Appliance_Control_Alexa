# ESP32-Based Home Appliance Control Using Amazon Alexa

## 1. Project Overview

This project demonstrates an IoT-based home automation system using an ESP32 microcontroller and Amazon Alexa.

The system allows users to control a fan through voice commands. ESP32 communicates over Wi-Fi and processes commands received through an IoT integration service.

**Project completion:** 2024  
**Documentation status:** Reconstructed from project recollection. Original implementation files and evidence are unavailable.

## 2. Objectives

- Develop a voice-controlled home automation system.
- Interface ESP32 with a fan control system.
- Understand Wi-Fi-based communication.
- Explore Amazon Alexa integration with IoT devices.
- Implement remote appliance switching.

## 3. Hardware Requirements

- ESP32 Development Board
- Relay Module
- Fan
- Suitable power supply
- Connecting wires

## 4. Software Requirements

- Arduino IDE
- ESP32 Board Support Package
- Amazon Alexa
- Wi-Fi connectivity
- IoT integration service (original platform not yet identified)

## 5. Working Principle

1. The user provides a voice command through Amazon Alexa.
2. The configured IoT integration service processes the command.
3. The command is communicated to the ESP32 through Wi-Fi.
4. ESP32 processes the received instruction.
5. The output control changes the relay state.
6. The fan is switched ON or OFF.
